# KARDS 网页版 — 二战卡牌游戏

对 **KARDS**（1939 Games 出品的二战数字集换式卡牌游戏）的网页/局域网复刻版。
原生 JS + Node.js 实现，**无需登录、无主页**，打开即玩。

> 玩家自制致敬版，与 1939 Games 官方无关。卡牌数据与美术素材版权归 1939 Games 所有。

---

## ✦ 功能特性

- **完整卡牌数据库 — 1638 张全带图卡牌**（已按要求剔除所有无图卡牌）：覆盖德国、美国、苏联、日本、英国、法国、意大利、波兰、芬兰、澳新军团、中立共 11 个阵营，含步兵 494、坦克 148、战斗机 141、轰炸机 96、火炮 55、指令 654、反制 50，收录至最新扩展包。
- **官方卡图**：手牌使用全尺寸卡面，棋盘使用缩略图；HQ 使用官方总部卡（但泽/瑟堡/斯大林格勒/特鲁克/伦敦等）。
- **还原度验证过的规则引擎**（30 条规则断言 + 16 条联机协议测试）：
  - 总部 20 点防御、指挥点每回合 +1（自然上限 12，卡牌效果可至 24）
  - **前线**归属权、支援阵线 5 格（含总部）、39 牌 + 1 总部卡组
  - 兵种：步兵、坦克（同回合移动+攻击，付双倍行动费）、火炮（无反击、可打任意目标）、战斗机（可拦截轰炸机）、轰炸机（无反击、无视守护）
  - 关键词：**闪击、奋战、守护、烟幕、伏击、冲击、重甲、隐蔽、部署、亡计** 等
  - 指令与反制、部署/亡计触发、+X/+Y 加成、抉择、卡组码解析
  - 行动费用（每次移动/攻击都消耗指挥点）、疲劳伤害、手牌上限 9、总部归零即胜
- **局域网联机**：创建房间 → 4 位房间码 → 好友在同一网络打开相同网址输入房间号 → 立即对战。服务端运行权威对局，手牌/牌库等信息按座位隔离。
- **人机对战**：启发式 AI 对手。
- **卡组构筑**：搜索、阵营筛选、按稀有度限制张数；另有 **8+ 套社区真实卡组**（官方卡组码导入）与自动组牌。
- **卡牌收藏浏览器**：搜索/筛选全部 1638 张卡牌。
- **复刻的战场 UI**：原版木纹桌面（无接缝）+ 透明摆件层（子弹/武士刀/皮面书/毛瑟手枪/旭日书册）、双方总部居中、虚线前线（占领后变金色/蓝色并显示归属）、扇形手牌、指挥官头像与橙色指挥点徽章。
- **全拖拽操作 + 动画**：拖牌部署/移动/攻击（幽灵牌 + 合法落点金框），攻击冲刺、命中火花、伤害数字、阵亡烟雾、总部抖动红闪、回合横幅、抽牌入场、卡牌悬停抬起。

## ✦ 快速开始

```bash
cd kards-web
npm install     # 安装依赖（ws）
npm start       # 启动服务器，监听 0.0.0.0:8080
```

然后打开：

- 本机：<http://localhost:8080>
- 同一 WiFi/局域网内的其他设备：**http://\<你的局域网IP\>:8080**（启动时会打印在控制台，开始页面也会显示）

联机方法：一人点击「创建房间」并告知 4 位房间码；另一人打开相同网址，点击「加入房间」输入房间码。

### 可选参数

```bash
PORT=9000 npm start                          # 自定义端口
KARDS_IMG_DIR=/路径/kards-img npm start      # 指定外部卡图库
```

## ✦ 玩法说明（60 秒上手）

1. 选择国家（决定卡组与总部），选择卡组（自动/社区/自定义）。
2. 点击「人机对战」或创建/加入局域网房间。
3. 每回合获得指挥点，把敌方总部从 20 点打到 0 即获胜。
4. 步兵与坦克必须先到**前线**才能攻击敌方总部与支援阵线；坦克可同回合移动并攻击（费用付两次）；火炮与空军可打任意目标，火炮永不受反击。
5. 部署当回合不能行动，除非拥有**闪击**。

### 操作方式（全部支持拖拽）

| 操作 | 方式 |
|---|---|
| 部署单位 | 从手牌**拖到**前线或支援阵线的任一空槽（松手即部署，目标槽位即落点） |
| 使用指令 | 点手牌两次，或点一次后点击目标 |
| 移动单位 | 把场上单位**拖到**前线/支援阵线的空槽（扣行动费） |
| 发起攻击 | 把单位**拖到**敌方单位或敌方总部上；也可点击单位进入瞄准模式再点目标 |
| 结束回合 | 右下「结束回合」 |
| 查看卡牌 | 鼠标悬停任意卡牌（含总部）显示详细信息 |

拖拽时：卡牌跟随光标（幽灵牌）、所有合法落点亮起金框、非法落点不响应；拖到空白处会自动提示并放回。
右键可取消瞄准状态。

## ✦ 表现层实现（动画 / 拖拽 / 视觉）

- **DOM 持久化渲染**：卡牌元素按 uid 复用，位置变化用 FLIP 补间（部署从手牌飞入、移动换槽、抽牌从桌外滑入），不会因重绘丢失动画。
- **战斗特效**：攻击冲刺 + 命中火花/冲击环/斩击线、伤害数字上浮、单位阵亡烟雾与旋转淡出、总部受击抖动 + 全屏红闪 + 防御数字跳动、回合横幅扫过、指挥点数字弹跳、可用卡牌金色呼吸光。
- **桌面**：`wood-base.jpg`（原版木板渲染调色，无接缝）+ `table-props.png`（子弹/武士刀/皮面书/毛瑟手枪/旭日书册透明摆件层）。
- **总部居中**：支援阵线为 `[槽][槽][总部][槽][槽]`，双方总部永远在屏幕中轴；前线是共享 5 槽横排。
- 设计稿 1280×720，按窗口等比缩放，任意分辨率不糊不乱。

## ✦ 已知限制

- 少量文本复杂的独特卡牌效果由模式匹配解释器处理（已覆盖约 40 种常见效果：伤害、抽牌、加成、摧毁、撤退、生成、指挥点效果、抉择、总部效果等）；无法识别的卡牌仍按普通单位正常使用并显示原效果文本。
- 卡牌美术为国际版英文卡面（官方素材），卡牌名称与效果文本保留英文原文。
